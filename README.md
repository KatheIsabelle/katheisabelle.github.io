# 🔮 Grimório da Kathe — Portfólio

Portfólio interativo de **Kathe Beserra**, game designer e desenvolvedora, no formato de um grimório de tarot em pixel art. Cada carta abre uma seção do site.

**🌐 Acesse: [katheisabelle.github.io](https://katheisabelle.github.io)**

---

## ✨ Sobre o projeto

Em vez de um portfólio tradicional, o site é um livro mágico com cinco cartas. Ao virar uma carta, você descobre uma parte do meu trabalho. Uma gatinha bruxa acompanha a visita e comenta o que está acontecendo.

| Carta | Conteúdo |
|---|---|
| **A Imperatriz** | Sobre mim e links de contato |
| **O Mago** | Jogos: MagiCards, Odisseia 2D, TNT Party Game, The Lonely Knight 2D e Adventure of Darkness |
| **O Mundo** | Publicações científicas (SVR, SBIE, ComIng, SIIEPE) |
| **A Estrela** | Ateliê: modelagem 3D, ilustração digital e vídeo |
| **A Roda da Fortuna** | Crônicas da Roda: blog (em construção) |

## 🛠️ Tecnologias

- HTML, CSS e JavaScript puros, sem frameworks e sem etapa de build
- Pixel art feita com CSS (`box-shadow` em camadas) e SVGs 16×16
- Layout responsivo para computador e celular
- Hospedagem no GitHub Pages

## 📁 Estrutura

```
├── index.html      # página única
├── style.css       # estilos
├── script.js       # cartas, seções, galerias e lightbox
├── .nojekyll       # publica o site sem processar com Jekyll
└── assets/         # imagens, fontes, sons e ícones
```

## 💻 Rodando localmente

Clone o repositório e abra o `index.html` em um servidor local, por exemplo a extensão **Live Server** do VS Code:

```bash
git clone https://github.com/KatheIsabelle/katheisabelle.github.io.git
cd katheisabelle.github.io
```

Depois, clique com o botão direito em `index.html` → **Open with Live Server**.
