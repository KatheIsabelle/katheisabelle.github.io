Royal Violet UI Kit
===================

A vivid violet interface pack — perfect for magic, puzzle, and casual games.

49 hand-tuned PNG UI elements, all with transparent backgrounds:

- Buttons (large + square icon): normal / hover / pressed / disabled
- Panels: large (with header) + small, drop shadows baked in
- Tooltip bubble with pointer tail
- Progress bars: frame + separate fill strips (health, mana, stamina, xp)
  plus pre-composed 75% examples — crop or scale the fill to any value
- Slider with knob
- Inventory slots: square (normal + highlighted) and circular
- Checkbox, radio button, and toggle switch (on/off states)
- Directional arrows (4) and close button
- Tabs (active/inactive), scrollbar track+thumb, dropdown, dialog box,
  notification badge, rating stars (on/off)

USAGE TIPS
- Bar fills are separate from frames: scale/crop the fill horizontally to show
  any value, keeping the rounded frame crisp.
- All elements share one palette, so they mix cleanly at any size.
- Need another color theme or element? Reach out — themes are generated from a
  parametric pipeline, so custom variants are quick.
